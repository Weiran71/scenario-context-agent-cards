# POI 推荐卡公开流程

## 输入

POI 卡读取用户偏好、常驻/到访状态、当前位置所在城区、当前时间、天气和候选 POI 池。每个 POI 至少有 ID、名称、距离、开放状态、标签、Summary 主题和卡片主题。

## 处理顺序

1. 根据时间、天气、位置和偏好形成潜在需求与约束记录。
2. 以距离和当前可用性建立候选边界。
3. 同时使用结构化标签和 Summary 主题计算匹配度。
4. 对候选进行排序，必要时选择 1～3 个具有共同主题的 POI。
5. 如果最高分不足以证明当前推荐价值，则输出 `stay_silent`。
6. 最后生成主题、主文案、副文案和内部推荐依据。

## 公开基线的取舍

基线优先保证可解释和可复现，不声称代表完整生产排序模型。真实系统可以替换距离函数、特征权重和语言模型，但必须保留“先形成需求、再选择候选、最后生成卡片”的顺序。
